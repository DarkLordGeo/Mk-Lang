# FLD-3's mutants: shallow loans in the writable walk.
# The format is
# mutants.txt's, read with it by readMutantTable (every
# tests/soundness/mutants*.txt, IDs unique across the files).
#
# Rows of class R name witnesses the tree rejects, and each mutant must flip
# every one to an acceptance with nothing emitted (TestFlowsMutants,
# MK_SOUND=1). Rows of class P are precision rows: they name
# witnesses the tree accepts, and each mutant must reject every one.
#
# The witnesses are tests/soundness/witness/fld3/*.mk. The 34 shallowB
# probes and 9 twins keep their measured verdicts (TestWitnesses), but
# every probe and twin that stores into a List puts its storage in an arena,
# and the allocator store rule stores a later hop's loans into that arena: the rejection
# then does not depend on FLD-3's marks, so none of them can be a row's
# witness (no such probe or twin flips under these
# mutants that the w-* witnesses do not). The w-* witnesses hold their
# references in a struct with no arena, so each depends on its row alone; the
# p-* witnesses are the precision pairs, with the allocator store rule's own clause written.
#
# No row cuts the readers of held sets: liveness, conflicts, results and B
# read held, and the marks are a separate set beside it (entry.sh,
# marks.go), which none of those readers looks at, so no such mutant can
# be written; the witnesses e02, e03, c09, c03 and twin-behind stay as
# witnesses.
#
#
#
# Parts of the shallow predicate with no row (pinned by
# internal/borrow/shallow_test.go; no program was found where one alone
# decides a verdict, so each is conservative given the others as far as
# the search could tell, which is not a proof):
# - the exclusive-step test (mut U): a mut reference to a carrier is
#   excluded by the carrier test, and through a mut reference to a
#   non-carrier the walk adds nothing (writable adds carriers only);
# - the ANY test: refSteps marks every ANY step exclusive, so the exclusive
#   test already excludes it;
# - writable by type as a referent: a referent writable by type that is no
#   carrier holds no loan, so the walk never adds it; and inline (a
#   Cell, Mutex or atomic by value), where the value's own loans target only
#   referents the other tests already judged;
# - the allocator test: std's Arena, Alloc and Heap are carriers, so the
#   carrier test excludes them in std;
# - the opaque tests (fn, type parameter, Self, inline or as a referent): a
#   witness would need a closure that stores a later argument into what it
#   captured, which no fn type can declare.

end
