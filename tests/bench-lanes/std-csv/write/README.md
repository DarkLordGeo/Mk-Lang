# csv-write (idiomatic table)

Workload: generate 200,000 records of 8 fields once (splitmix64, seed 42; each field 0 to 11 bytes over a 40-byte alphabet of letters, digits, space, comma, quote and LF, so about a third of the fields need quoting and some quotes are doubled), write them `reps` times through each standard library's CSV writer into an in-memory buffer cleared before each rep, then read the last output back through a file with the same library's reader.

Checksum (values): the records, the fields, the field bytes and the sum of the field bytes read back. The output bytes differ (Go quotes a field that starts with a space and ends records with LF; Mk quotes only where RFC 4180 needs it and ends records with CR LF), the values do not.

| Column | Writer | Buffer |
|---|---|---|
| mk | `csv.WriteRecord` per record (8 views of one generated byte list) | one `Text`, `Clear` before each rep, written through `Text.Writer` (no inline buffer: one call per piece) |
| go | `encoding/csv` `Writer.Write` per record, `Flush` per rep | one `bytes.Buffer`, `Reset` before each rep |
| c, rust, zig | no std CSV writer | |
